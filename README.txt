# Vansh — YouTube Thumbnail Designer Portfolio

## Run in VS Code

1. Open this folder in VS Code.
2. Open `index.html` with **Live Server** (recommended), or double-click `index.html`.
3. All images are already inside `assets/`.

## Easy edits

- Main text/content: `index.html`
- Colors, layout, responsive design: `styles.css`
- Thumbnail popup + scroll animations: `script.js`
- Logo: `logo.svg`

## Portfolio images

The project contains only the thumbnail samples supplied for this portfolio.
